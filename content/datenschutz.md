## 2. Bereitstellung und Hosting über Cloudflare

Der Blog wird als statische Website über Cloudflare Pages bereitgestellt. Beim Abruf verarbeitet der Hosting-/CDN-Anbieter technisch notwendige Verbindungsdaten, insbesondere IP-Adresse, Zeitpunkt, angeforderte Ressource, Referrer (sofern übermittelt), Browser und Betriebssystem. Die Verarbeitung dient der Auslieferung, Stabilität und Sicherheit des Angebots.

Anbieterinformationen und Hinweise zu internationalen Datentransfers: [Cloudflare-Datenschutzerklärung](https://www.cloudflare.com/privacypolicy/). Die konkrete Rechtsgrundlage, Auftragsverarbeitung und Löschfristen müssen für das eingesetzte Cloudflare-Konto noch abschließend geprüft werden.

## 3. Lokale Funktionen

Der Blog setzt keine eigenen Analyse- oder Marketingdienste ein. PaperMod speichert die gewählte Hell-/Dunkelansicht und die horizontale Menüposition im lokalen Speicher des Browsers. Diese Angaben verlassen den Browser durch die Website selbst nicht. Pagefind durchsucht einen statisch erzeugten Index direkt im Browser; Suchbegriffe werden vom Blog nicht an einen Suchdienst übertragen.

## 4. YouTube-Videos {#youtube-videos}

Videos werden zunächst nur als lokaler Hinweis mit einem externen Link angezeigt. **Ohne Klick auf „YouTube-Video laden“ wird kein YouTube-Player und kein YouTube-Vorschaubild geladen.** Erst nach der bewussten Aktivierung wird ein Player von `youtube-nocookie.com` eingebettet. Dann werden technisch erforderliche Daten wie IP-Adresse, Browserinformationen, aufgerufene Seite und gegebenenfalls Kontoinformationen an Google/YouTube übertragen; eine Verarbeitung außerhalb der EU/des EWR kann nicht ausgeschlossen werden.

Anbieterhinweise: [Datenschutzerklärung von Google](https://policies.google.com/privacy). Alternativ kann das Video über den sichtbaren Direktlink auf YouTube geöffnet werden.

## 5. Giscus-Kommentare {#giscus-kommentare}

Kommentare werden über Giscus und GitHub Discussions bereitgestellt. **Ohne Klick auf „Kommentare laden“ wird das Giscus-Skript nicht geladen.** Nach der Aktivierung baut der Browser Verbindungen zu Giscus und GitHub auf. Dabei können insbesondere IP-Adresse, Browserdaten, die aufgerufene Seite und – bei Anmeldung – GitHub-Kontoinformationen verarbeitet werden. Für das Schreiben eines Kommentars ist ein GitHub-Konto erforderlich; der Kommentar wird öffentlich in GitHub Discussions gespeichert.

Anbieterhinweise: [Giscus-Datenschutz](https://github.com/giscus/giscus/blob/main/PRIVACY-POLICY.md) und [GitHub-Datenschutzerklärung](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement). Die datenschutzrechtliche Freigabe, Rechtsgrundlage und Löschpraxis sind vor Veröffentlichung abschließend zu prüfen.
